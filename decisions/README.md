# Decision records

Each decided subject is one `DR-####` file in this folder, numbered in order and listed here. This folder holds the only copy of each decision record of 49GAION; the companion repositories link here. The status of each record is kept only in this index.

**Frozen records (DR-0006).** A record file on main never changes. A new record takes the next free number in merge order. A row of this index changes only in its Status cell: from proposed to in force, or from in force to superseded by a newer record. A required check on main enforces this.

## Reading notes

- Records written before v1.1.0 may name a person and carry a Status line of their own. The index above governs status; those records are not edited.
- DR-0002 item 1, "Any unit, AIOC or HOAC, may be composed of smaller units of either kind": superseded (DR-0004): an AIOC may hold other AIOCs and its own Pods and Cells; HOAC is a label, not a unit.
- Decisions are recorded under "the governing seat (GOV) of 49GAION".

# DR-0018 · 49GAION — One return contract between design stages

- **Date:** 2026-10-15
- **Decided by:** the governing seat (GOV) of 49GAION (holder in the private holders register)
- **Source:** the directions of the governing seat (GOV) of 49GAION of 2026-10-15: "Let us send the upstream proposals and merge them." (translated), on the proposal drafted in the writing repository of Process and Position Design that its return contract become a Library contract.
- **Relation:** builds on DR-0014, DR-0016 and DR-0017; it supersedes nothing.
- **Number:** this record takes the next free number at merge, after DR-0017

## Decision

1. **One contract.** Every design stage that reads the release of the stage before it sends its returns under one Library contract, `library/contracts/design-return.schema.json` in `49GAION-protocol`, with its valid and must-fail examples.
2. **Five kinds.** Accepted; cannot use, naming what is missing; contradiction found; assumption invalid; request kind unsupported. A return names release parts, elements and fact-types, with evidence by reference, never a person, and never carries new release text.
3. **It always ends.** A return is open, then ends in one of: answered by release; answered by decision; set aside by decision and carried forward on a stated basis (known defect or decided assumption); withdrawn. Each answered or set-aside return names what answered it. Each round is counted.
4. **Filed.** An open return has its copy filed in Source Lifecycle with the same hash.
5. **Version.** The contract sits on main under the unreleased `v1.6.0`.

# DR-0044 · 49GAION — the mothers of the design chain in repositories of 49GAION

- **Date:** 2026-10-25
- **Decided by:** the governing seat (GOV) of 49GAION (holder in the private holders register)
- **Source:** a finding made while bringing the repositories into line with the complete definition (DR-0041): three parts of the Library were pinned in the repositories of a first instance, named by that organisation's unit codes; the proposal of 2026-10-25 to move them; and the governing seat's word the same day (translated): "Yes."
- **Relation:** applies DR-0024 (a mother repository for a Library part) to the three parts it did not yet cover. It changes no rule of any part and removes nothing.

## Decision

1. **Three mother repositories.** The Library parts 49GAION Target Operating Model, 49GAION Process and Position Design and 49GAION Delivery and Implementation have mother repositories of their own, public, under the pattern of DR-0024: `49g-holding/49GAION-target-operating-model`, `49g-holding/49GAION-process-and-position-design` and `49g-holding/49GAION-delivery-and-implementation`.
2. **Moved unchanged.** Each receives every tracked file of the first instance's repository at the commit the Library register pins, as it was. Each blueprint keeps its version and its SHA-256: Target Operating Model `v0.6.1`, Process and Position Design `v0.5.1`, Delivery and Implementation `v0.2.1`. Each mother adds only its own record of the move, with the readings of DR-0041 and DR-0042, its index row, a README head, and its state and changelog rows.
3. **The Library register re-pins the three parts** at their mother repositories, the same path, the same version, the merged commit and the same SHA-256, by one pull request to `49GAION-protocol`. The assembly 49GAION Organisation Design and Delivery moves its pins the same way, by a pull request to its own repository.
4. **Why.** A text of 49GAION points only to 49GAION. A repository named by one organisation's unit code is that organisation's own, not the Library's; an organisation that takes a part from the Library finds it under the Library's own name. The three parts predate DR-0024.
5. **The first instance's repositories** are that organisation's own and are not texts of the Library. Whether it keeps, archives or renames them is its own matter, outside 49GAION.
6. **Version.** Unreleased. The version labels and `state.json` stay as they are until GOV releases.

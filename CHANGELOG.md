# Changelog

The hub keeps its history in two places, by design:

- **Release notes,** one file per released version: [`RELEASE-NOTES/`](RELEASE-NOTES/). The current version is `v2.0.0`.
- **Decision records,** one file per decision of the governing seat, never edited, indexed with their status: [`decisions/README.md`](decisions/README.md).

Between releases, every change to `main` is a merged pull request that cites its decision record. `STATE.md` names the records on `main` that are not yet in a release.

# 49GAION Standard v1.5.0

Approved by the governing seat (GOV) of 49GAION. Decisions: [`DR-0006`](https://github.com/49g-holding/49GAION/blob/main/decisions/DR-0006-decision-record-lock.md) (decision records frozen; how a change reaches main) and [`DR-0007`](https://github.com/49g-holding/49GAION/blob/main/decisions/DR-0007-49gaion-v1-5-0-structure-accountability-signatures.md) (structure, accountability, signatures, gateway and register).

## Summary

- Two relations and the root: `parent` for where a card is held, `accountable_to` for the human Cell a part answers to.
- Labels GOV, TM and ACS on human Cells, decision bodies and the signer rule for listed decision types.
- Skip-level reporting, recusal, stops and held actions; held actions never run because time has passed.
- Twenty-one decision types added to the Human Floor signature list; optional policy fields declared.
- The tool gateway as a registered part outside every AIOC, failing closed.
- Unit register: new event types, five new columns without backfill, a status map, and fillers kept in a private holders register. The GOV row is corrected to seat only.
- Delivery test D-4, accountability chain in place.
- Decision records are frozen: a record on main never changes and new records take the next free number.

## Checks on main

Required checks gain github-separation, dr-frozen and ci-selftest. The no-org-names check also judges added or changed lines against a private list of person names, reporting path and line only and failing closed.

## Known limits

- The person-name check proves its given-name variant forms only through fictional selftest cases; no run on real text exercises those forms.

# The 49GAION Guide

The plain-language text of 49GAION: what it is, how it works, and how an organisation starts with it. It is written from the complete definition (`49GAION-FRAMEWORK.md`) and explains it; it decides nothing. Where the guide and the definition differ, the definition governs (DR-0042, item 7).
